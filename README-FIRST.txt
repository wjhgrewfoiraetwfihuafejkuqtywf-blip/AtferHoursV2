AFTERHOURS — START HERE

Welcome! This is the first homepage version of AfterHours.

FILES
- index.html: the homepage structure and game cards
- style.css: the blue cyber dashboard design
- script.js: search, filters, profile nickname, theme toggle, and starter achievements

HOW TO PUT IT ON YOUR WEBSITE
1. Download and unzip AfterHours-Website.zip.
2. Open your website's GitHub repository.
3. Choose Add file > Upload files.
4. Upload index.html, style.css, and script.js.
5. If GitHub says index.html already exists, STOP. Do not overwrite it. This is a new site, so use a new empty repository or make a separate folder such as /afterhours/ and upload all three files there.
6. Commit the files.
7. Open the published website.

IMPORTANT
- This is a front-end starter. It does not create online accounts or store shared data.
- The profile name, avatar initial, achievement progress, and selected accent are saved only in the current browser using local storage.
- The game buttons are placeholders for now. The listed titles need legitimate playable sources or official game pages connected in a later step.
- The web proxy tile is only a placeholder. It is not a working proxy and is not intended to bypass school, work, or network restrictions.
- The music panel is a playlist placeholder. Music playback and music accounts need a music source/provider in a later update.
- Do not paste secret API keys into these files.
